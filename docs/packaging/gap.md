## Why this is not packaged further

The existing entry point is `deep-ad-slot analyze`. The weekly run is CronJob `deep-ad-slot-weekly`. The k3s console unsuspends and suspends that CronJob. A new dashboard would be a second controller and would fetch publisher sites. This packaging does not run an analyze and does not add an AdSense site. Stop here. This is not an authorization to operate.
